## 260605-3 / 260605-4 带色引文并非逐字
- 规则：blog-writer《带色引文必须逐字回查》（反例记 260605-4）/ blog-researcher《官方原话在 `## 信息来源` 里逐字，叙述节的转写必须一眼可辨》+《评审指认引用不逐字时，比对基准是信源原文》（反例记 260605-3）
- 链条：2026-07-28 一天内三次复现。260605-3 红字复述微博官方 #微博附注#，把"所示内容""目前已受到屏蔽处置"改写成"涉事内容""已对该博文予以屏蔽处置"，以近乎逐字又略有出入的形态呈现官方认定；260605-4 灰字把法官 Mrozinski 的第三人称转述（"she had not seen anyone as prolific"，所有原始报道均无引号）包装成直接引语，另有一处红字概述重复时间线细节。
- 更正（2026-07-31，用户裁定）：原记"两案的研究文件本身逐字无误，偏差均在写作阶段引入"，对 260605-3 不成立。该研究文件同时存在两个版本——`## 信息来源` 逐字准确（"目前已受到屏蔽处置"），`## 当事方` 已转写为"对该条博文予以屏蔽处置"、`## 事实` 亦把提示语段改写；写手草稿的两处偏离正与转写节措辞吻合。update 模式的研究回合又断言"与本研究文件上文及信息来源节所载逐字一致，无误……系草稿写作阶段转述改写"，把同一归因错误再确认了一遍。据此更正 blog-writer《带色引文必须逐字回查》的比对基准：只认 `## 信息来源`／信源原文，不认 `## 事实`／`## 当事方`。260605-4 的原归因（偏差在写作阶段）不受影响。
- 出处：_pipeline/review 下 260605-3、260605-4 各 v1 评审文件（问题 1 / 问题 3）；_pipeline/research/260605-3-研究生遭造谣与网暴.md 第 11／27／37 行。

## 260717-4 / 260705 / 260705-2 来源行 URL 落在本站追踪账号上（安全事故）
- 规则：blog-researcher《转发帖不作来源》下"微博 URL 绝不能落在本站追踪账号上"与"不许拿转发者的帖子 URL 去挂原作者的名字"两款 / `src/linter.py` 的 `tracked_uids()` 机械闸口
- 链条：`src/.env` 的 `TRACKED_UIDS` 是本站的事件发现源。研究阶段从追踪账号的博文里读到媒体报道**截图**，因"媒体官微原帖需登录微博方可访问"就直接用了博主帖的 URL 入 `## 信息来源`。研究文件本身老实写了转录链条（"转录自该报道截图，截图附于网民 X 此条博文"），但**链条说明进不了草稿的来源行**——来源行只剩"媒体名 + 博主帖 URL"，于是同时造成两个后果：①把本站追踪账号公开挂在已发布文章里；②来源归属错误，读者点开看到的是博主的评论帖而非所标媒体的报道（`weibo.com/1934276677/R97q0hRLi` 经 `wbfetch.py` 核实 `retweet_text` 为空，是追踪账号本人 2026-07-17 18:24 的评论帖，却被登记为"2026.07.16，海报新闻"，来源名/日期/性质三样全错）。审计时已泄露 5 条、分布在 3 篇已发布文章。补救时另查出一处连带错误：当事人回应的灰字原话站上写作"不是花招"，三个独立信源统一为"不是**起号**"（直播行业术语，指靠剧本刻意打造账号涨粉），系研究阶段转录截图手误。
- 处置：三家媒体均在网页端找到自己的原始出处（新浪转载的海报新闻、澎湃转载的潮新闻谢春晖署名稿、澎湃转载的中国新闻周刊），`260705` 的转发帖定位到原帖（"萌萌真叫人头大"，非追踪账号），均已替换并重新发布。规则要点：媒体官微被登录墙拦住就走网页端，网页端也取不到就把该媒体说法降级为"仅截图转录、无可核验原始出处"，**宁可不收，不许借博主 URL 充数**。
- **已裁定的例外（2026-08-04，`source/_posts/260705-2.md`）**：该文来源 `https://weibo.com/1934276677/R7h0PnzjT` 经核实**不是转发**，是追踪账号本人的原创举报帖，且帖子末尾挂着微博官方"围脖侠"针对**这一条具体博文**做出的"微博附注"回应（"已视情节予以阶段性禁言处置"）。微博附注挂在被标注博文页面上、不是独立博文，检索确认该回应只存在于这一个 URL。删除即丢掉全文唯一的蓝字最新进展。用户裁定**保留**该 URL。清洗存量文章时不要把这条当漏网"修"掉——它是经裁定的例外，`linter.py` 对它会报 FAIL 属预期。
